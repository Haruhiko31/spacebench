# Référence API

Le backend SpaceBench expose une API REST construite avec [FastAPI](https://fastapi.tiangolo.com/).
Une documentation interactive est générée automatiquement et disponible aux endpoints suivants une fois le backend démarré.

---

## Documentation interactive

### Swagger UI

Interface interactive complète — testez n'importe quel endpoint directement depuis le navigateur, inspectez les schémas de requête/réponse et consultez les descriptions des paramètres.

[http://localhost:8000/api/docs](http://localhost:8000/api/docs)

### ReDoc

Documentation de référence épurée et en lecture seule. Mieux adaptée à la lecture qu'aux tests.

[http://localhost:8000/api/redoc](http://localhost:8000/api/redoc)

!!! note "ReDoc hors ligne"
    ReDoc est servi depuis un fichier statique local (`redoc.standalone.js`) — il fonctionne sans connexion internet.
